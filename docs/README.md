# 📖 SplitFlow Documentation Suite

Welcome to the **SplitFlow** technical and user documentation hub. This directory contains comprehensive references, architectural guides, smart contract API documentation, frontend integration details, and deployment walkthroughs for SplitFlow on Stellar Soroban.

---

## 🗂️ Documentation Index

| Guide | Description | Target Audience |
|-------|-------------|-----------------|
| 🏗️ **[Architecture Overview](./ARCHITECTURE.md)** | System architecture, sequence diagrams, component workflows, RBAC security, and basis-point (BPS) payment split math | Architects & Reviewers |
| 🔐 **[Smart Contracts Reference](./SMART_CONTRACTS.md)** | Technical specification for `RoyaltyManager` and `RoyaltyDistributor` Soroban Rust contracts (functions, structs, events, storage keys) | Smart Contract Engineers |
| ⚡ **[Frontend & SDK Integration](./FRONTEND_INTEGRATION.md)** | Direct reference for `@stellar/stellar-sdk` RPC server calls, `StellarWalletsKit` wallet integration, transaction simulation, and state stores | Web3 Frontend Developers |
| 🛠️ **[Deployment & CI/CD Guide](./DEPLOYMENT_GUIDE.md)** | Step-by-step local setup, Rust/WASM compilation, Stellar Testnet contract deployment scripts, and GitHub Actions workflow | DevOps & Maintainers |
| 👤 **[User & Onboarding Guide](./USER_GUIDE.md)** | End-to-end walkthrough for creators and payees covering wallet connection, asset registration, executing payouts, and tracking history | Creators & End Users |
